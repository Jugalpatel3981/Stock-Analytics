# Frontend

Next.js 15 application for the AI Stock Intelligence Platform.

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run typecheck
```

## Environment

Copy `.env.example` to `.env.local` and update values as needed.

## Routes

- `/` (landing page with demo login)
- `/login`
- `/register`
- `/dashboard`
- `/stocks`, `/stocks/[ticker]`
- `/watchlists`, `/portfolio`
- `/news`, `/assistant`
